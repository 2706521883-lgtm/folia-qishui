## 一、这是什么

- **Folia 二创版（folia-qishui）**：在 [chthollyphile/folia-major](https://github.com/chthollyphile/folia-major) 基础上二次创作的音乐播放器。
- 基础版本：上游 **v0.7.17** 的完整源码。
- 许可证：**AGPL-3.0**（不是 GPL-3.0）。上游原始 README 保留在 `README.original.md`，上游贡献者、文档、CI 配置都保留。
- 本版自 **0.3.1** 起独立编号，所以 `0.6.x` 比上游 `0.7.x` 小是正常的；第一次从官方版换到本版（或换回去）需要手动装一次安装包。

## 二、二创功能

| 功能 | 说明 | 主要落点 |
|---|---|---|

| 壁纸引擎背景 | 扫描本机 Wallpaper Engine 场景并采集为背景层 | `electron/wallpaperEngine*.cjs`、`src/components/visualizer/backgrounds/we/` |

| 波点音乐音源 | 搜索、播放、歌词 | `src/services/onlineMusic/bodian*`、`electron/bodian*` |
| 跨音源聚合搜索 | “全部音源”一次搜遍所有已登录平台 | `src/services/onlineMusic/federatedSearch.ts` |
| 自动换源 | 歌曲下架/播放失败时到其他音源找同一首 | `src/services/onlineMusic/crossSourceFallback.ts` |
| 队列融合 | 切换在线平台不清空播放队列 | `src/stores/usePlaybackStore.ts` 等 |
| Lattice 队列拼贴 | 歌单点击后整张进队列并进入拼贴墙 | `src/library/app/usePlaylistLatticeOpener.ts`、`src/components/app/lattice/` |

详细功能说明以 `README.md` 为准。

## 五、版本号规则

- 版本号在 `package.json`，格式 `0.x.y`，与上游无对应关系。
- 每个版本一条 `release/<版本>` 分支；发布在 `folia-updates` 打 Release。
- `main` 分支当前严重落后，**不是当前代码**；以最新 `release/*` 分支为准。
- 发布前必须得到用户明确授权，见 `06-约束与决策记录.md`。

## 六、改名规则（名称是变量）

### 6.1 三类名字，风险不同

| 类型 | 例子 | 处理方式 |
|---|---|---|
| **展示名** | 界面品牌、README/手册标题、安装包显示名 | 直接改，注意文案与截图 |
| **结构标识** | `package.name`、`productName`、`appId`、用户数据路径、安装目录 | 先做迁移方案；**不要全局盲替换** |
| **外部身份** | GitHub 源码仓库、Release 仓库、remote URL、更新源、桌面/传输文件夹 | 同步改；旧地址尽量保留重定向/别名 |

**关键警告**：改 `appId` / `productName` 可能让老用户变成“新应用”——设置、缓存、登录态、自动更新链都会受影响。除非同时设计数据迁移和发布说明，否则优先只改展示名，保留 `appId`。

### 6.2 改名流程

1. 先改本文件顶部的“项目身份”表。
2. 全仓库搜索旧名：
   ```bash
   rg -n "旧名" --glob '!node_modules/**' --glob '!release/**' --glob '!dist/**'
   git remote -v
   ```
3. 判断每个命中项属于展示名 / 结构标识 / 外部身份；结构标识先定迁移方案。
4. 改代码与构建配置：`package.json`（name/productName/appId/build.publish/artifactName）、`electron/main.cjs`（发布 URL、用户数据路径相关）、i18n、UI 品牌文案。
5. 改外部身份：GitHub 仓库名/remote、Release 仓库、更新源、桌面手册目录、传输文件夹、快捷方式。
6. 重新构建、安装，验证：启动、更新检查、用户数据是否还在、安装目录是否正确。
7. 更新手册：`01` 身份表、`02/03` 路径、`04` 构建发布、`05` 当前状态、`06` 决策、`09` 日志；旧名只在**一处**保留“曾用名/迁移说明”。
