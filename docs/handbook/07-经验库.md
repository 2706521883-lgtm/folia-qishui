## EXP-0001 壁纸引擎底部白/黑边

- **现象**：WE 场景壁纸底部出现一条纯白或纯黑边，换壁纸也一直在。
- **根因**：引擎创建窗口后先有边框，随后剥掉边框，客户区变大；引擎的渲染表面仍是旧尺寸，没有收到尺寸变化。
- **解决**：剥框/停靠后向引擎窗口发送 `WM_SIZE`，让它按最终客户区重建；PowerShell 回退路径用 1px 高度抖动达到同样效果。
- **识别特征**：日志里 `resizeNotified:false`；底部像素颜色均匀且不随壁纸内容变化（采样标准差接近 0）。
- **边界**：只影响 Windows 场景壁纸；视频壁纸不走这条链路。
- **相关文件**：`electron/wallpaperEngineWindowNative.cjs`、`electron/wallpaperEngineWindow.cjs`。
- **版本/日期**：0.6.11 / 2026-10-24。

## EXP-0002 暂停时更换 WE 壁纸黑屏

- **现象**：音乐暂停时更换 Wallpaper Engine 壁纸，画面全黑，音乐开始后才显示。
- **根因**：新采集流挂上来时 `paused` 仍为 true，`video.play()` 被跳过；同时首帧未到就把海报隐藏了。
- **解决**：把“音乐暂停”和“窗口不可见”拆开（`windowHidden`）；只有隐藏/最小化才挂起采集；用 `hasFrame` 控制海报与视频显隐；视频首帧前 `visibility:hidden`；重挂载时用已采集画面做种子。
- **识别特征**：黑屏只在暂停状态出现，恢复播放即好；采集流本身是活的。
- **边界**：所有 WE 场景壁纸；与音频播放状态解耦。
- **相关文件**：`src/components/visualizer/backgrounds/we/WeBackground.tsx`、`WeBackgroundLayer.tsx`、`WeBuiltinVideoLayer.tsx`、`src/components/visualizer/useVisualizerRendererModel.ts`。
- **版本/日期**：0.6.11 / 2026-10-23。

## EXP-0003 重启后 WE 壁纸不恢复

- **现象**：每次启动应用，之前设置的壁纸引擎壁纸要重新打开/调整。
- **根因**：主进程的 WE 库索引在设置卡扫描前是空的；启动时按 itemId 查不到条目，返回 `unknown-item`，也没有重试。
- **解决**：启动后延迟预扫描（有已保存 itemId 时）；`wallpaper-engine-start` 与 `folia-we://` 协议都加惰性 `ensureFresh(false)` 兜底；日志记录 `unknown-item`。
- **识别特征**：设置卡打开一次后恢复正常；主进程日志出现 `unknown-item` 或库为空。
- **相关文件**：`src/App.tsx`（预扫描 effect）、`electron/main.cjs`、`electron/wallpaperEngineLibrary.cjs`。
- **版本/日期**：0.6.11 / 2026-10-23。

## EXP-0004 面板关着点“音频效果器”没反应

- **现象**：播放器右上角快捷控制里点“音频效果器”没反应；先点左下角“打开面板”后对话框才冒出来。
- **根因**：`AudioEqualizerDialog` 只挂在面板的 `ControlsTab` 里；点击只把 `isAudioEqualizerOpen` 置 true，没有组件渲染。
- **解决**：对话框提升到 `App.tsx` 应用层，`ControlsTab` 移除；补 UI 测试覆盖“面板关闭时从侧栏打开”。
- **识别特征**：store 里 `isAudioEqualizerOpen=true`，但 DOM 里没有对话框；打开面板后立刻出现。
- **相关文件**：`src/App.tsx`、`src/components/panelTab/ControlsTab.tsx`、`src/components/panelTab/AudioEqualizerDialog.tsx`。
- **版本/日期**：0.6.11 / 2026-10-24。

## EXP-0005 git push 连不上 GitHub

- **现象**：`git push` 报 `Failed to connect to github.com:443 after 21s`；`api.github.com` 却是 200。
- **根因**：全局 per-host 代理指向 `127.0.0.1:8899`，但本机 GitHub 通道没在运行；同时 `github.com` 的 DNS IP 可能正处在封锁窗口。
- **解决**：绕过失效代理并钉一个实测可用的 IP：
  ```bash
  git -c http.https://github.com/.proxy= \
      -c http.curloptResolve=github.com:443:20.233.83.145 \
      push origin <branch>
  ```
  IP 从 `E:\harmessDS\_gh\ip-pool.txt` 取，或 `curl --resolve` 逐个测试。也可以启动 GitHub 通道或 VPN。
- **识别特征**：api 通、github.com 超时；8899 端口未监听；`curl --resolve` 换 IP 后 200。
- **版本/日期**：2026-10-24。

## EXP-0006 打包时 ECONNRESET

- **现象**：`npm run build:electron` 在 `packaging` 阶段报 `read ECONNRESET`。
- **根因**：electron-builder 下载/校验 Electron 或打包依赖时网络瞬断，缓存不完整。
- **解决**：直接重试一次通常就过；仍失败时检查 `%LOCALAPPDATA%\electron\Cache` 与 `electron-builder\Cache`，必要时挂代理。
- **识别特征**：堆栈落在 `got` / `ClientRequest`，失败点在 `packaging` 之后。
- **相关文件**：`package.json` 的 `build:electron`。
- **版本/日期**：2026-10-24。

## EXP-0007 安装版启动即退出

- **现象**：从 shell 启动打包版 Folia，进程一闪而过，没有窗口。
- **根因**：当前 shell 环境里有 `ELECTRON_RUN_AS_NODE=1`，Electron 被当成 Node 运行。
- **解决**：启动前清掉：
  ```powershell
  Remove-Item Env:ELECTRON_RUN_AS_NODE -ErrorAction SilentlyContinue
  Start-Process "$env:LOCALAPPDATA\Programs\Folia\Folia.exe"
  ```
- **识别特征**：进程启动后立即退出；开发模式正常。
- **版本/日期**：2026-10。

## EXP-0008 播放器近乎空屏 / 歌词不动

- **现象**：播放器只剩深色背景、底栏和角落按钮；进度在走（如 01:02），但歌词时钟停在 0。
- **根因**：可视化桥只在真正播放时更新 `currentTime` / `lyricCurrentTime` / `currentLineIndex`；暂停或跳转后歌词时间没同步。经典视觉器 `showText=true` 且 `currentLineIndex=-1` 时没有可显示的行，而 `ui.waitingForMusic` 在所有语言里都是空字符串。
- **解决**：加暂停状态下的主舞台歌词同步分支；无歌词行时兜底显示歌曲名 + 歌手。
- **识别特征**：进度条在动、歌词索引 -1、歌词时间 0；背景不是纯黑但没有任何文字。
- **相关文件**：`src/hooks/usePlaybackVisualizerBridge.ts`、`src/components/visualizer/classic/Visualizer.tsx`。
- **版本/日期**：0.6.11 / 2026-10-24。

## EXP-0009 点歌单进了集合页而不是拼贴墙

- **现象**：从首页/播放器侧栏点歌单，先进入 Bravais 集合页或海报页，队列没有整张写入。
- **根因**：走的是集合层导航，受“播放后进入的视图”全局偏好影响，还会先压栈再异步退回。
- **解决**：统一用 `usePlaylistLatticeOpener`：解析整张歌单 → 同步写入队列 → 静默起播 → 显式 `navigateToLattice`。250ms 合并连点、300ms 才显示加载提示、12s 补页兜底、最后一次点击生效、可取消。
- **识别特征**：hash 不是 `#lattice`；`lattice-poster` 不存在或队列为空。
- **相关文件**：`src/library/app/usePlaylistLatticeOpener.ts`、`src/components/app/GridViewOverlayHost.tsx`、`src/App.tsx`。
- **版本/日期**：0.6.10 / 2026-10-23。

## EXP-0010 汽水打包后不能播放

- **现象**：开发模式汽水正常，打包后播放/签名失败。
- **根因**：`bdms.node`、`metasecml.dll` 等原生文件被打进 asar，运行时加载不到。
- **解决**：在打包配置里对 `electron/qishui/qishui-auth-v6/` 做 `asarUnpack`；安装后检查 `resources/app/electron/qishui/qishui-auth-v6/` 下文件是否存在。
- **识别特征**：日志报原生模块加载失败；dev 正常、packaged 失败。
- **相关文件**：`package.json` 的 build 配置、`electron/qishui/`。
- **版本/日期**：0.6.x。

## EXP-0011 大安装包上传 GitHub 失败

- **现象**：`curl` 直传 Release 资产报 56/55，速度只有 ~220KB/s，最后中断。
- **根因**：线路对 GitHub 上传限速/阻断。
- **解决**：走本地 mihomo 代理 `http://127.0.0.1:9674`，必要时 `curl --http1.1`；安装包、blockmap、`latest.yml` 分开传；上传后核对 SHA-256 与 `latest.yml`。
- **识别特征**：直传卡住/重置；换代理后速度到 MB/s。
- **版本/日期**：0.6.10 / 2026-10-24。
