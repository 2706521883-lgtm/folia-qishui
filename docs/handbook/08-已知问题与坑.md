| 问题 | 影响 | 当前绕行 | 备注 |

## 二、构建与网络

| 问题 | 影响 | 当前绕行 |
|---|---|---|
| `package-lock.json` 与 `package.json` 漂移 | `npm ci` 报 EUSAGE | 用 `npm install` |
| electron-builder 偶发 `read ECONNRESET` | 打包失败 | 重试；仍失败检查缓存/代理 |
| GitHub 通道可能没有自动启动 | `git push`/网页打不开 | 启动 `E:\harmessDS\_gh\github-channel.ps1`，或按 EXP-0005 钉 IP |
| `ELECTRON_RUN_AS_NODE=1` | 安装版启动即退出 | 启动前 `Remove-Item Env:ELECTRON_RUN_AS_NODE` |
| GitHub 大文件上传不稳 | Release 资产上传中断 | 走 mihomo `127.0.0.1:9674`，分文件上传并校验哈希 |

## 三、壁纸引擎

| 问题 | 影响 | 当前绕行 |
|---|---|---|
| 老机器/低端 Win10 + 较旧 GPU 的采集兼容性 | 可能回退到 `getDisplayMedia` 或采集失败 | 已有现代通道回退；需在目标机器回归 |
| 多屏/缩放变化后的停靠 | 可能短暂位置错误 | 窗口管理器会重新停靠；需实测 |
| 场景窗口被外部重建 | 可能丢采集 | 监控与孤儿清理已做；异常时看主进程日志 |

## 四、流程与仓库

| 问题 | 影响 | 当前绕行 |
|---|---|---|
| `main` 严重落后 | 从 main 拉分支会拿到旧代码 | 从最新 `release/*` 拉 |
| 本地标签不完整 | 不能只靠 tag 判断线上版本 | 以 `folia-updates` Release/API 为准 |
| 「传输」文件夹混放对外资料 | 内部文档可能误发 | 手册放桌面 `Folia-项目手册`，不放传输文件夹 |
| 桌面手册镜像可能过期 | 新会话读到旧状态 | 每次收尾同步；以仓库 `docs/handbook/` 为权威 |
| 网盘/云盘副本未纳入自动同步 | 在外地可能拿不到最新手册 | 靠 `05` 台账的时间戳人工对比 |
