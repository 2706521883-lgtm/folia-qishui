# 约束与决策记录

> 最后核对：2026-10-24 ｜ 本文件只保留**当前有效**的约束和决策；被取代的决策删除或压成一行。

## 一、硬性约束（用户原话）

> **“我只允许在播放器访问国内镜像网站进行更新。”**

> **“我不希望别人在镜像网站里面可以直接下载到我的程序。”**

落地含义：

1. 更新检查/下载必须走国内镜像，不能让播放器直接依赖境外更新源。
2. 镜像站不能把安装包暴露成任何人都能直接下载的静态文件；需要鉴权、签名 URL 或等效保护。
3. 安装包**不放进公开仓库**，也不在聊天里外发。
4. **未经用户明确授权，不发布任何版本。** 0.6.10 是授权后发布的；0.6.11 目前只允许留在本地。

## 二、其他不可违反的约束

- 不覆盖、不删除原作者信息；上游 `README.original.md`、贡献者、AGPL-3.0 授权必须保留。
- 不把账号、Cookie、Token、API Key、本机路径写进源码或提交。
- 汽水登录凭据（`electron/qishui/credentials.cjs` 写入的文件）是本机明文，只在本机，不提交、不外发。
- 源码仓库只放源码；安装包只在 `folia-updates` 的 Release 里。
- `package-lock.json` 与 `package.json` 有漂移，构建用 `npm install`，不要用 `npm ci`。
